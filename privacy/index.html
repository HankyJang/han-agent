사용 대상

이 앱은 운영자 본인(장한결) 한 명만 사용합니다. 다른 사람의 계정 연결을 받지 않습니다.

접근하는 데이터

Google 계정의 이메일 주소·기본 프로필과 Gmail 메시지(읽기 전용, gmail.readonly 범위)에 접근합니다. 메일 발송·수정·삭제 권한은 요청하지 않습니다.

사용 방법

데이터는 운영자 본인의 개인 컴퓨터에서 메일 검색·요약에만 쓰입니다. 제3자에게 판매하거나 공유하지 않으며, 광고에 쓰지 않습니다.

보관과 삭제

인증 토큰은 운영자 컴퓨터에만 저장됩니다. Google 계정 설정(myaccount.google.com/permissions)에서 언제든 접근 권한을 해제할 수 있습니다.

Google API로 받은 정보의 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.
